# ODG Algeria — Project Description

**ODG Algeria** is the national digital platform for Algeria’s network of youth institutions (*Office des Établissements des Jeunes* — ODEJ). It connects young people, youth clubs, and public administrators across all **69 wilayas** with a single, multilingual web experience.

The platform makes it easy to discover youth houses, cultural centres, sports facilities, and camps; follow news and events; register for training; and access dedicated programmes such as **Khilya** (listening and support) and **Diwan** youth projects. An interactive map of Algeria lets users explore institutions by wilaya, while authenticated spaces support day-to-day operations: youth dashboards, club programme submission, and an admin back-office for content and approvals.

Built as a modern **React** single-page application with **Arabic (RTL)**, French, English, and Kabyle, ODG Algeria is designed for mobile-first use, accessibility, and low-bandwidth contexts. The current repository ships with a rich **mock API** (localStorage) for demonstrations and hackathons; production deployment is intended to connect to a secure backend, PostgreSQL database, and optional AI assistant (Groq) for ODG-related questions only.

**Target users:** young citizens, youth club managers, ODEJ staff and administrators, and partners.

**Core value:** one trusted entry point for youth services, participation, and transparency at national scale.
